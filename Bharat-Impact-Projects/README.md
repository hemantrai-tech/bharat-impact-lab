# Bharat Impact Projects

Nine independent apps, each with its own frontend, backend, workflow, and SQLite database.

## Open everything

On Windows, double-click `Start-Projects.bat`. It starts nine local backends and opens `index.html`, where each project has its own Open project button. To start only one app, open its folder and double-click `run.bat`.

Python 3.9 or newer is required. No third-party packages are needed. Each project creates its own `data.sqlite3` on first launch.

## Projects

- [JalRakshak](./jalrakshak/) — Water reliability
- [SaansMap](./saansmap/) — Neighborhood air
- [KisanSetu](./kisansetu/) — Farmer market access
- [SeekhoSaath](./seekhosaath/) — Learning practice
- [SwasthyaSetu](./swasthyasetu/) — Care continuity
- [KaamNirmaan](./kaamnirmaan/) — Skills to paid work
- [SurakshaSaathi](./surakshasaathi/) — Private safety planning
- [SwachhChain](./swachhchain/) — Waste traceability
- [HaqSaathi](./haqsaathi/) — Public entitlements

Use fictional or non-sensitive data. Health and safety prototypes avoid collecting clinical details, phone numbers, or exact addresses. Current government rules, air readings, jobs, and water reports need qualified local verification before real-world use.
