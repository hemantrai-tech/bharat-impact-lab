NINE INDEPENDENT LOCAL APPS

Bharat Impact Projects

Each project focuses on one everyday challenge with a working interface, its own backend, and a separate SQLite database.

First: open the Start-Projects.bat file in this folder. It starts all nine local backends. Then use each “Open project” button below. Python 3.9+ must be installed.
